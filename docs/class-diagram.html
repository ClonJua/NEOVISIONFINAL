Notas

Se muestran las clases más relevantes: entidades del dominio y las interfaces de servicio que orquestan los casos de uso principales. Se omiten DTOs, repositorios, mappers y controladores por legibilidad.

Atencion agrupa el formulario clínico en ~13 objetos @Embedded (Anamnesis, AgudezaVisual, Refraccion, Queratometria, FormulaFinal, Lensometria, Motilidad, ExamenExterno, FondoOjo, PruebasComplementarias, Conducta, DatosGenerales); en el diagrama solo se listan cuatro a modo de ejemplo.

Cita.version y Atencion.version implementan bloqueo optimista (@Version) para evitar escrituras concurrentes perdidas.
