Notas del modelo

ATENCION tiene ~190 columnas (el formulario clínico completo, con prefijo por sección: an_ anamnesis, av_ agudeza visual, dg_ datos generales, ee_ examen externo, ff_ fórmula final, fo_ fondo de ojo, lm_ lensometría, mt_ motilidad, pc_ pruebas complementarias, qm_ queratometría, rf_ refracción, cd_ conducta, sv_ signos vitales) — se omiten del diagrama por legibilidad; el detalle completo va en el diccionario de datos del manual.

ATENCION.id_cita es UNIQUE: una cita origina como máximo una atención.

AUDITORIA y META_PACIENTES_SEMESTRE no tienen llaves foráneas (por diseño: la auditoría conserva usuario_correo como texto para no perder trazabilidad si la cuenta se borra).

Se excluye shedlock: tabla técnica del scheduler de citas/recordatorios, no es una entidad de dominio.
